    넣으면 새로고침 때 유튜브 조회수·구독자를 바로 읽는다. 구글 클라우드 콘솔에서 YouTube Data API v3를 켜고 만든 키 — 키 제한을 "HTTP 리퍼러 opop4615.github.io/*"와 "YouTube Data API v3"로 걸어 둘 것.

    넣으면 새로고침이 서버 수집(플레이·차트·리뷰)까지 바로 돌린다(1~2분). 세분화 토큰(fine-grained)으로, 저장소는 opop4615.github.io 하나, 권한은 Actions: Read and write 하나만.

    서버 수집은 한 시간마다(매시 17분 무렵) 깃허브 액션이 돈다 — 플레이 페이지·검색, 앱스토어 차트·리뷰, 유튜브(키가 없으면 최근 15편). 명예의 전당·앱스토어 페이지·검색 순위는 새로고침할 때 이 브라우저가 직접 읽는다 실시간.
